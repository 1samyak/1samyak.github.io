# Samyak Jain — Portfolio

This folder contains the static portfolio site for Samyak Jain.

## Published URL

https://1samyak.github.io/samyak-portfolio/

The repository-level GitHub Actions workflow deploys the repository root, including this folder, to GitHub Pages. The portfolio is served from this subdirectory.

## Local preview

Open index.html in a browser. No build step or package installation is required.

## Files

- index.html — page structure and content
- styles.css — responsive visual system
- script.js — section navigation and active-section state
- assets/favicon.svg — site icon
- assets/avatar.svg — local avatar fallback

## Before sharing

Verify the education and programme descriptions and revise any wording that is no longer current. The site intentionally does not publish a personal email address or phone number.
